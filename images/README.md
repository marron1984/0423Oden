# images

マーケティング用画像素材を格納するフォルダです。

## ディレクトリ構成

- `week4-decision/` … 第4週「意思決定」向け画像
  - 目的: 今行く理由を作る
  - 訴求軸: 今月だけのコース / 旬のピーク / 今しか味わえない食材 / 限定性 / 季節感
  - ターゲット: 30〜50代経営者の接待、40代以上の会食
  - 最重要価値: 失敗しない安心感

## 画像の追加方法

1. 対応するサブフォルダに画像ファイル（jpg / png / webp 等）を配置
2. `git add images/<サブフォルダ>/<ファイル名>`
3. `git commit -m "add: <用途> 画像を追加"`
4. `git push origin <ブランチ名>`
